# Third-party notices

The generic challenge shield icons and their SVG sources are original artwork authored for this extension. They do not derive from Anubis's mascot artwork. Selecting them changes only the three image responses; upstream attribution in the challenge pages remains intact.

The standard installer downloads Anubis 1.28.1 by Techaro/Xe Iaso during installation, using the version and SHA-256 recorded in `runtime.lock.json`. Optional offline builds include that verified release. Full upstream archive contents are retained, including additional notices. Anubis's source is available at https://github.com/TecharoHQ/anubis/tree/v1.28.1.

Administrators may separately download other stable official releases. Each runtime cache retains the full upstream archive, including its version-specific license and notices. Runtime selection does not replace the bundled policy snapshot or its provenance.

The extension also includes a flattened JSON snapshot of Anubis 1.28.1's default policy rules, covered by the same MIT license above. `sbin/data/rules-provenance.json` records source URLs and SHA-256 hashes for every imported source file. Database-dependent rules are omitted at generation time when GeoIP is disabled; other rule contents and ordering are retained.

MaxMind databases are supplied by the administrator or downloaded with the administrator's MaxMind credentials. No GeoLite2 database or MMDB reader library is bundled. Database metadata is validated using the host's separately installed `mmdblookup` utility from AlmaLinux's `libmaxminddb` package. Test MMDB files are original empty databases generated by the tests, containing no third-party IP data.

Plesk provides the extension API on the host. Plesk vendor code is not bundled in this project's source archive. Test fixtures are original minimal configurations modeled on documented Plesk routing behavior.
